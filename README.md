# SuperChirps — Releases

Public downloads and the [Sparkle](https://sparkle-project.org) auto-update feed
for **SuperChirps**, a privacy-first dictation app for macOS (Apple Silicon).

- **Source code** lives in a separate private repository.
- Each release here ships `SuperChirps.zip` and an `appcast.xml` that the app
  uses to check for and install updates.

## Install

1. Download `SuperChirps.zip` from the [latest release](../../releases/latest), unzip it,
   and move **SuperChirps.app** to your Applications folder.
2. First launch: right-click the app → **Open** → **Open Anyway** (one-time, since
   the app is self-signed rather than App Store / notarized).
3. After that, the app updates itself — no need to come back here.
